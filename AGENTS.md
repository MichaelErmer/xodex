# Repository Instructions

- Use Conventional Commits for commit messages, for example `feat: ...`, `fix: ...`, `docs: ...`, or `chore: ...`; add a scope when it adds clarity.
- Make surgical changes. Keep edits tightly limited to the requested behavior and the nearby code needed to support it.
- Do not add dependencies unless explicitly asked or clearly required for the requested feature.
- Avoid unnecessary project bloat. Do not introduce abstractions, helper layers, generated artifacts, or extra files whose size or complexity would be larger than the feature being worked on.
